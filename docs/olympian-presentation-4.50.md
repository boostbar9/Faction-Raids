# Olympian presentation and spellbook review

Iron's 1.20.1-legacy reference pinned at b928995887aa362467fa999a9c9fb86419f00f2d. Read FireballSpell, IcicleSpell, LightningBoltSpell and AbstractMagicProjectile in https://github.com/iron431/irons-spells-n-spellbooks. Their useful architectural separation is charge/cancel, aimed travel, swept collision, client trails and server impact. This implementation is independent; no Iron's source or assets are redistributed. No new required dependency.

The previous books damaged a box around the caster. The new Creative-only books launch bounded original projectiles with vanilla swept collision, vanilla rendering and particles. Fire splashes within two blocks with visibility checks, ice slows, lightning travels quickly, and water emits eight pulses over two seconds with pushback. Allies and players are excluded. Projectiles expire within 40 ticks/48 blocks, stop before unloaded chunks, and cannot change terrain. The existing hero AI powers are not silently rebalanced by these Creative book changes.

Weapon skins use original 32px pixel art generated by tools/generate_olympian_weapon_models.py, and inherit vanilla transforms instead of custom cuboid grip math. Vanilla items, enchantments and native Recruits weapon behavior remain authoritative. No player animation library or copied animations.

Verified code defects: generic names from Recruits finalizeSpawn were treated as player renames by hero identity initialization; territory descriptions reserved purchase-button space but not the status line; starter gates used an offset diagonal opening while sanctuary routing expected a centered mature-gate approach. New camps now share a five-wide entrance. Existing saved core locations are never moved or overwritten. Existing offset gates now have a bounded, dry single-file fallback route when a wider outer avenue is absent. The sanctuary still requires the same safe site and three clear entrance stairs. Existing camps are not torn down to retrofit gates. Unsafe terrain can still defer a core; this release does not claim every missing-core report is reproduced.

No interactive Minecraft playtest was performed. Automated tests cover lifecycle and geometry contracts, not perceived animation quality in a running modpack. Final source/build/artifact/upload receipts belong in the PR release comment.

Review follow-up: the retained supply list is [0,1,4,5,6,8,9,12,13,14], so the reserved relic is present and the nine-entry remainder is correct. Retired-material reachability tests now match the intended pool, with explicit absence checks. Pixel tests replace cuboid-only assumptions. Frost has a separate original icon. The narrow saved-gate route reserves its outside threshold against later construction.
