# Repository agent guide

Read [.github/copilot-instructions.md](.github/copilot-instructions.md) for shared project constraints and [CONTRIBUTING.md](CONTRIBUTING.md) for build, architecture and release guidance. These are the common handoff documents for Copilot and other coding agents.

Use current source and the assigned task to establish scope. Complete one reviewable change at a time, preserve existing work, and record validation and remaining limitations in the PR. Keep these documents synchronized when architecture or development commands change.
